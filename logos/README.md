# Logos

Drop your logo images in this folder. The home page looks for these file names:

| Tool | File |
|---|---|
| HSR Chat | `hsr-chat.svg` |
| ZZZ Chat | `zzz-chat.svg` |
| Nikke Chat | `nikke-chat.svg` |
| Persona IM | `persona-im.svg` |
| Chat Reel | `chat-reel.png` |
| GBF Story Maker | `gbf-story-maker.svg` |
| Visual Novel | `visual-novel.png` |
| Motion Comic | `motion-comic.png` |
| Delivery Reel | `delivery-reel.png` |
| Photo Frame Studio | `photo-frame-studio.png` |
| Photo Splitter | `photo-splitter.png` |
| Video Layers | `video-layers.png` |
| Metadata Scrubber | `metadata-scrubber.png` |

Square images look best (for example 512 × 512). Until a file exists, the square shows a
colored letter mark instead. To use a different file name or format (SVG, JPG, WebP), change
the `image` entry for that tool in the `SECTIONS` list at the top of the script in
`../index.html`.
